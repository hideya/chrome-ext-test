# chrome-ext-test

## Window Color Manager 🎨

Chrome拡張機能で、複数のウィンドウを色分けして作業を整理できるツールです。各ウィンドウの上部に色付きバーを表示し、どのウィンドウがどの作業に属するかを一目で判別できます。

![Window Color Manager Demo](https://img.shields.io/badge/Chrome-Extension-4285F4?style=for-the-badge&logo=googlechrome&logoColor=white)

## 🚀 機能

- **ウィンドウ単位の色分け**: 各Chromeウィンドウに異なる色を設定
- **自動色適用**: 新しいタブを開くと自動的にそのウィンドウの色が適用
- **タブドラッグ対応**: タブを他のウィンドウに移動すると、移動先の色に自動更新
- **プリセット色**: よく使う8色のプリセットカラー
- **カスタム色**: 自由に色を選択できるカラーピッカー
- **プレビュー機能**: 色を設定前に確認できるプレビューモード
- **データ永続化**: 設定した色はブラウザ再起動後も保持

## 📥 インストール方法

### 開発版として読み込む場合

1. **開発者モードを有効にする**
   - Chromeを開き、アドレスバーに `chrome://extensions/` と入力
   - 右上の「デベロッパーモード」をオンにする

2. **拡張機能を読み込む**
   - 「パッケージ化されていない拡張機能を読み込む」ボタンをクリック
   - このプロジェクトのフォルダを選択
   - 「選択」をクリック

3. **拡張機能の確認**
   - Chrome右上の拡張機能メニュー（パズルピースアイコン）をクリック
   - 「Window Color Manager」が表示されていることを確認

## 🎯 使い方

### 基本的な使用方法

1. **色を設定する**
   - Chrome右上の拡張機能メニューから「Window Color Manager」をクリック
   - ポップアップが開いたら、好きな色をクリックして選択
   - またはカスタムカラーピッカーで任意の色を選択し「適用」をクリック

2. **効果を確認する**
   - ページの最上部に5pxの色付きバーが表示されます
   - 新しいタブを開いても同じ色が自動適用されます

3. **複数ウィンドウでの活用**
   - 新しいウィンドウを開く（Cmd+N / Ctrl+N）
   - 各ウィンドウで異なる色を設定
   - ウィンドウを切り替えて色分けによる識別を活用

### 高度な機能

- **プレビューモード**: 「プレビューモード」ボタンをクリックして有効にすると、色の上にカーソルを置くだけで一時的に色を確認できます
- **色の削除**: 「色を削除」ボタンで現在のウィンドウの色設定をリセット
- **タブの移動**: タブを他のウィンドウにドラッグ&ドロップすると、移動先のウィンドウの色に自動的に変更されます

└── README.md              # このファイル

### コードの変更後の再読み込み手順

1. **ファイルを編集**
   - 任意のエディタでファイルを変更・保存

2. **拡張機能を再読み込み**
   - `chrome://extensions/` を開く
   - 「Window Color Manager」の「🔄」（再読み込み）ボタンをクリック

3. **動作確認**
   - 変更が反映されているかテスト
   - エラーがある場合は「エラー」リンクをクリックして詳細を確認

### デバッグ方法

- **バックグラウンドスクリプトのデバッグ**:
  - `chrome://extensions/` → 「詳細」→「バックグラウンドページを検査」
  - Console タブでログやエラーを確認

- **コンテンツスクリプトのデバッグ**:
  - 任意のページでF12を押してデベロッパーツールを開く
  - Console タブでエラーやログを確認

- **ポップアップのデバッグ**:
  - 拡張機能アイコンを右クリック → 「ポップアップを検査」

## 🎨 カスタマイズ例

### 色バーの高さを変更

`content.css` の `.window-color-bar` セクション：
```css
.window-color-bar {
  height: 8px !important;  /* デフォルトは5px */
}
```

### プリセット色の追加

`popup.html` の `.color-palette` セクションに新しい色を追加：
```html
<div class="color-option" data-color="#YOUR_COLOR" style="background: #YOUR_COLOR;" title="カスタム色"></div>
```

## 🐛 トラブルシューティング

### よくある問題

**Q: 色が適用されない**
- A: ページをリロード（F5）してみてください
- A: 一部のChrome特殊ページ（`chrome://`など）では動作しません

**Q: アイコンが表示されない**  
- A: アイコンファイルがなくても機能は正常に動作します

**Q: 新しいタブで色が適用されない**
- A: 拡張機能を再読み込みしてみてください
- A: バックグラウンドページでエラーが出ていないか確認してください

**Q: 設定した色が保存されない**
- A: Chrome のストレージ権限が正しく設定されているか確認してください

### エラーログの確認方法

1. `chrome://extensions/` を開く
2. 「Window Color Manager」の「エラー」をクリック（表示されている場合）
3. または「詳細」→「バックグラウンドページを検査」でコンソールを確認

## 🌐 公開手順

### Chrome Web Store での公開

1. **Chrome Developer Dashboard への登録**
   - [Chrome Developer Dashboard](https://chrome.google.com/webstore/devconsole/) にアクセス
   - Googleアカウントでログイン
   - 初回の場合、$5の開発者登録料を支払い

2. **拡張機能のパッケージ化**
   - 本番用にmanifest.jsonのバージョンを更新
   - アイコンファイル（16px, 48px, 128px）をPNG形式で追加
   - 不要なファイル（開発用ログなど）を削除
   - プロジェクトフォルダ全体をZIPファイルに圧縮

3. **ストアへのアップロード**
   - 「新しいアイテム」をクリック
   - ZIPファイルをアップロード
   - ストア掲載情報を入力：
     - タイトル
     - 詳細な説明
     - スクリーンショット（1280x800推奨）
     - カテゴリー選択
     - 言語設定

4. **審査と公開**
   - 「審査のために送信」をクリック
   - 審査には通常数日～数週間かかります
   - 承認後、自動的にChrome Web Storeで公開されます
